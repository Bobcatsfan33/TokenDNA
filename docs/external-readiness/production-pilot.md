# Production Pilot and Customer Acceptance

Owner: design-partner customer and TokenDNA product/operations leads

Run a time-bounded pilot using real operational workflows and a release
candidate identical to the proposed production artifact.

Required evidence:

- agreed success metrics and representative agent/security use cases;
- deployment record pinned to image digest and configuration revision;
- measured detection efficacy, false-positive burden, latency, and availability;
- integration, usability, support, and operator-response findings;
- resolved go-live blockers and documented residual risks;
- customer and product acceptance signatures.

Acceptance: success metrics are met in a production-like customer environment,
no Critical/High blocker remains, and both parties authorize general rollout.
